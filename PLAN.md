# Portrait Plan

## Criteria

Reads clearly at small size.

## A — geometry

Explored on Branch A

- Gives the face a friendly, playful look

## B — assets

Explored on Branch B

- Image 1: a hat on top of the head
- Image 2: glasses over the eyes
  (Probably would draw these myself)

Note: I ended up deciding to add images for my assets instead of drawing them myself.

## C — color and curves

Explored on Branch C

- A gradient on the head from orange to yellow
- A Bézier curve for a smiling mouth

## Decision: C

I chose branch C because it fit my criteria of being able to be read at a small size. The smile and shading is clear enough to distinguish the differences between the original face and can be seen at any size. The freckles in branch A turn into specks at a small size, and for B well, I wanted it to merge the 2 together but for this assignment it was not possible. So I made the hard decision to rebase and push C onto the main branch.
